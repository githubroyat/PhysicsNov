# Oscillations & Waves Trainer

A test-prep website for secondary-school physics: oscillations and waves, built from class notes (Oct–Nov).

- Topic pages: Hooke's law, describing oscillations, damping, pendulums, resonance, waves
- Interactive simulations (spring, oscillator, unit circle, pendulum, resonance, wave on a string)
- 165 practice questions, endless calculation practice, flashcards and a timed mock test
- Content beyond the class notes is marked "Extra"

Progress is saved only in your own browser (local storage).

Live site: https://githubroyat.github.io/PhysicsNov/
